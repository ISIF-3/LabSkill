LabSkill v0.2.0은 과거 트렌딩 기록을 최근 1년으로 확대하고 대량 목록을 60개씩 페이지로 보여줍니다.

- 요청 범위는 2025-10-22~2026-10-22입니다. 고정 원본에는 2026-10-21까지 365일의 기록과 고유 저장소 1266개가 있으며, 2026-10-22는 아직 게시되지 않았습니다. 화면에 기록 범위와 `365/366일 기록 · 원본 없는 날짜 1일`을 표시합니다.
- 초기 공개 시작 목록은 1286개입니다. 명단의 중복을 기존 목록과 비교해 합치고 필요한 현재 GitHub 정보를 Python으로 분류합니다. 기본 모델 호출·모델 토큰 사용은 0입니다.
- 새 항목 495개 중 489개의 정보를 수집했습니다. 조회되지 않는 신규 6개와 기존 2개도 명단에 유지하며, 앱에서 정리를 다시 시도할 수 있습니다.
- 검색·필터·정렬은 전체 목록에 적용하고 카드만 60개씩 표시합니다. 총개수와 기능별 개수는 전체 결과를 기준으로 합니다.
- 기존 목록·북마크·컬렉션·메모는 유지합니다. 과거 명단의 첫 정보 보강에는 New!를 붙이지 않으며 이후 신규 등록과 실제 내용 변경의 7일 New! 표시는 유지합니다.
- 설치 의존성은 이전 버전과 같습니다. Python 3.11 등 Python 3.10 이상이 이미 설치되어 있으면 그대로 사용합니다. 전용 로컬 포트와 실행 오류 구분 안내도 유지합니다.

트렌딩 원본은 커밋 `83e0423605b47c34751141d79deb16ab3942504b`로 고정했습니다. 같은 범위를 다시 가져오는 CLI와 원본 검증 방식은 `labskill-catalog/imports/README.md`에 있습니다. 이후 추가한 도구와 개인 메모·북마크는 각 사용자의 컴퓨터에 저장합니다.

- macOS ZIP: Apple Silicon·macOS 12 이상, `LabSkill.app` 실행. Python 3.10 이상을 별도로 설치해야 합니다. 현재 로컬용 ad-hoc 서명이며 Developer ID 서명·Apple 공증을 받은 배포물이 아닙니다.
- Windows ZIP: `LabSkill.bat` 실행. Python 3.10 이상, WebView2 Runtime, `requirements-windows.txt` 설치가 필요합니다. 실제 Windows GUI 실행은 아직 검증하지 않았습니다. `.exe`나 설치 프로그램이 아닙니다.
- 새 GitHub 정보 수집에는 본인의 GitHub CLI 로그인이 필요합니다. 저장된 목록은 오프라인에서도 탐색할 수 있습니다. 기본 분류에는 Codex나 모델 API가 필요하지 않습니다.
- 압축을 쓰기 가능한 폴더에 풀고 앱과 `labskill-catalog/`를 함께 둡니다. 기존 사용자는 자신의 목록·메모·북마크를 별도로 보관하며 새 ZIP으로 기존 데이터 폴더를 덮어쓰지 마세요.

상세 실행 방법은 ZIP의 `시작하기.md`와 `README.md`를 참고하세요.

GitHub 링크 직접 추가, Python 분류, 컬렉션과 개인 메모 저장, 내용 변경 후 7일간 New! 표시도 사용할 수 있습니다.
