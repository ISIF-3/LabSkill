GitHub 주간 트렌딩과 분야별 검색, 과거 트렌딩 기록에서 발견한 저장소를 모으고 README 원문을 근거로 분류하는 로컬 도구 라이브러리입니다. ‘+ 추가’에서 GitHub 링크를 직접 넣을 수 있습니다.

모든 저장소를 코드·개발, 문헌 검색, 시각화 등 기능별 목록에서 탐색합니다. 여러 기능을 가진 도구는 여러 목록에 함께 나타나며, 기능을 알 수 없는 항목도 기타·미분류에 보관합니다. 세부 필터에서 종류와 지원 앱을 좁힐 수 있습니다. 지원 앱 표시는 README 안내 기준입니다.

기본 분류는 파일 신호와 README 키워드를 Python 규칙으로 비교합니다. 모델을 호출하지 않으며, 제목은 종류 템플릿이고 요약은 원문 소개를 사용합니다. 이전에 저장한 분류 결과도 함께 보관합니다.
