# 트렌딩 명단 원본

`trending-history-2026-04-18_2026-10-18.json`은 antonkomarev/github-trending-archive의 고정 커밋 `b783f6c0e7f486376943cdb7fcbe33d6d03ee858`에서 읽은 전역 일간 기록이다. 184일 모두 비어 있지 않았으며, 등장 2,771건을 대소문자 구분 없이 합친 명단은 771개다. JSON에는 각 기록의 경로·Git blob 해시·순위·날짜와 중복 제거 결과를 함께 보관했다. 내려받은 184개 파일의 Git blob 해시를 대조했다.

같은 이름의 CSV는 사람이 검토하기 위한 명단이다. source의 현재 별 수나 과거 주간 증가량을 추측해 넣지 않았다. 날짜별 순위는 daily 순위다. 현재 README·라이선스·별 수는 이 명단을 앱 카탈로그에 가져온 뒤 별도로 읽는다.

원본: https://github.com/antonkomarev/github-trending-archive

고정 커밋과 라이선스: https://github.com/antonkomarev/github-trending-archive/blob/b783f6c0e7f486376943cdb7fcbe33d6d03ee858/LICENSE

`licenses/antonkomarev-MIT.txt`에 원본 라이선스 고지를 보관했다.

`weekly/2026-10-18.json`은 가져오기 형식의 최초 예시이며, 이 앱이 실제 수집한 이번 주 10개 목록이다. 앱의 정식 주간 기록은 이후 `../weekly/YYYY-Www.json`에 저장한다. 같은 주에 수동 갱신하면 그 주 파일이 최신 수집으로 갱신되며 이전 주 파일은 유지한다.

모든 저장소의 실제 목록·분류 결과 원본은 계속 `../catalog/catalog.json` 하나다. imports 파일은 출처를 보관하는 원본 자료다. GitHub 원격 저장소에 파일을 올리지 않는다.
